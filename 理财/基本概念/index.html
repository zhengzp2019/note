一、核心理念

  • 复利：利息再生利息，时间越长效果越显著。年化10%，7.2年本金翻倍（72法则）。
  • 通货膨胀：钱会贬值，不投资本身就是一种"亏损"。中国近年CPI约2-3%，实际通胀体感更高。
  • 风险与收益成正比：高收益必然伴随高风险，没有"低风险高收益"的产品，遇到了大概率是骗局。
  • 不懂不投：不理解的产品不要碰，先学习再投资。

二、投资品种

低风险

  • 货币基金：如余额宝，年化约1.5-2%，随存随取，适合放零花钱。
  • 国债：国家信用担保，3年期约2.5%，5年期约2.7%，几乎无风险。
  • 银行定期存款：保本保息，受存款保险保护（50万以内）。

中风险

  • 债券基金：投资一篮子债券，年化约3-6%，短期可能小幅亏损，持有1年以上大概率正收益。
  • 可转债：兼具债券保底和股票上涨潜力，面值100元，到期还本付息，涨了可以转股获利。

高风险

  • 股票：公司发行的所有权凭证，买入即成为公司股东。收益不封顶，亏损也可能很大。
  • 指数基金：跟踪一篮子股票，分散了个股风险但仍有市场波动风险。
  • 中国：沪深300（最大300家公司）、中证500（中型500家）、创业板指（偏科技创业）
  • 美国：标普500（最大500家）、纳斯达克100（科技股偏多）、道琼斯（30家蓝筹）
  • 主动管理基金：基金经理主动选股，表现取决于经理能力，费用较高。

其他

  • 黄金：抗通胀、避险资产，不产生现金流，靠价格波动赚钱。
  • 房产：兼具居住和投资属性，流动性差，门槛高。

三、关键概念

  • 大盘指数：反映整个市场整体走势的指标，相当于市场的"体温计"。中国的"大盘"一般指上证指数。
  • 牛市与熊市：牛市指市场持续上涨、投资者乐观；熊市指市场从高点下跌超20%、投资者悲观。"熊市播种，牛市收获"。
  • ETF：交易型开放式指数基金，像股票一样在交易所买卖，跟踪特定指数，费率低。
  • 净值：基金每份的价格，净值涨了就是赚了。
  • 年化收益率：把任意时间段的收益折算成一年的收益率，方便横向对比。
  • 最大回撤：从最高点到最低点的最大跌幅，衡量"最坏情况能亏多少"。
  • 夏普比率：每承担一份风险获得多少超额收益，越高越好。
  • K线（蜡烛图）：展示价格走势最常用的图表，每根K线记录开盘价、收盘价、最高价、最低价。红色阳线表示收盘>开盘（涨），绿色阴线表示收盘<开盘（跌）。注意中国红涨绿跌，美股相反。常见形态：大阳线（强势上涨）、大阴线（强势下跌）、十字星（多空博弈可能变盘）、长上影线（冲高回落压力大）、长下影线（探底回升支撑强）。按时间周期分为日K、周K、月K和分钟K线。

四、股票的类型

常见分类

类型 计价货币 上市地 主要投资者
A股 人民币 上海/深圳/北京交易所 境内为主，境外可通过沪深股通参与
B股 美元（沪）/港币（深） 上海/深圳交易所 原面向境外，现境内也可
H股 港币 香港交易所 境外为主
  • A股：全称"人民币普通股票"，是中国境内注册公司发行、以人民币交易的股票，也是内地投资者最主要的交易品种。
  • 红筹股：在境外注册、主营业务在内地的公司（如中国移动），也多在香港上市。与H股的区别在注册地（H股为境内注册），而非上市地。

命名由来

  • A、B股按字母顺序排：A股是最早的本土股票，用第一个字母A；B股是1992年推出、针对境外投资者的外币股，顺次用B。
  • 境外上市股按城市首字母：境内公司到境外上市时，用上市地城市英文首字母命名。
类型 上市地 取名来源
H股 香港 Hong Kong 香港首字母
N股 纽约 New York 纽约首字母
S股 新加坡 Singapore 新加坡首字母
L股 伦敦 London 伦敦首字母

一句话：境内上市按字母排序（A、B）；境外上市按城市首字母（H、N、S……）。

A股的板块划分

上面的 A/B/H 股是按"计价货币和投资者"横向分类；A股内部还可以按"在哪个交易所的哪个层次上市"纵向分成不同板块，通常对应公司的规模和类型。

板块 所属交易所 定位 涨跌幅 代码开头 开户门槛
主板 上交所/深交所 成熟大型企业 ±10% 沪600/601、深000/001 无特殊要求
创业板 深交所 成长型创新企业 ±20% 300、301 2年经验 + 10万资产
科创板 上交所 "硬科技"企业（半导体、生物医药等） ±20% 688 2年经验 + 50万资产
北交所 北京证券交易所 创新型中小企业 ±30% 43/83/87、920 2年经验 + 50万资产
  • 两个维度别混淆：A股 vs B股/H股是"用哪种货币、给谁买"（横向）；主板 vs 科创板 vs 创业板是"公司在哪个梯队上市"（纵向）。
  • 科创板、创业板的股票同时也是A股，只是门槛更高、涨跌幅更宽。
  • 新股上市初期涨跌幅更宽松：创业板/科创板前5个交易日不设涨跌幅限制。

A股交易规则

  • T+1：当天买入的股票，次日才能卖出（资金T+0，卖出后当天可再买）。
  • 涨跌幅限制：主板 ±10%，创业板/科创板 ±20%，北交所 ±30%，ST股 ±5%。
  • 交易单位：买入以"手"为单位，1手=100股，卖出可不足100股（零股一次性卖出）。
  • 交易时间：工作日 9:30-11:30、13:00-15:00（9:15-9:25为集合竞价）。

五、实用策略

定投

  • 原理：固定时间投入固定金额，高位少买、低位多买，摊平成本。
  • 适合品种：宽基指数基金（沪深300、中证500、标普500）、行业指数基金。
  • 不适合：单只股票（风险集中）、货币基金/短债（波动太小没意义）。
  • 关键：坚持，尤其是下跌时不停止；设置止盈点（如收益30-50%时分批卖出）。

资产配置

  • 核心思想：不把鸡蛋放在一个篮子里，不同资产之间相关性低可以降低整体风险。
  • 简单配置示例（仅供参考）：
  • 保守型：货币基金40% + 债券基金40% + 指数基金20%
  • 均衡型：货币基金20% + 债券基金30% + 指数基金50%
  • 激进型：货币基金10% + 债券基金20% + 指数基金/股票70%

投资纪律

  • 只用闲钱投资，至少留3-6个月生活费作为应急资金。
  • 不加杠杆（不借钱炒股）。
  • 设定买入和卖出规则，避免情绪化操作。
  • 长期持有，减少交易频率（频繁交易手续费吃掉收益）。

六、开户指南

账户类型

账户类型 能买什么 在哪开
证券账户 股票、ETF、可转债、场内基金、国债逆回购 券商APP（如华泰、中信、东方财富）
基金账户（场外） 场外基金（货币基金、债券基金、指数基金等） 支付宝/微信/天天基金/券商APP/基金公司官网

说明：证券账户功能最全，开一个基本覆盖所有品种；场外基金账户门槛最低、操作最简单，适合定投入门。

证券账户开户流程

  1. 选择券商：重点关注佣金费率（建议万1-万1.5）和APP体验
  2. 下载券商APP，点击"开户"
  3. 准备材料：身份证 + 银行卡（一类卡）
  4. 按提示完成：身份验证 → 视频认证 → 设置密码 → 绑定银行卡
  5. 等待审核（通常当天或次日通过）
  6. 开通完成后进行银证转账（把银行卡里的钱转入证券账户）

券商选择建议

券商 佣金 特点
东方财富 万1-万1.5 互联网券商，费率低，APP功能全，基金数据丰富
华泰证券 万1.3-万2 老牌券商，涨乐财富通APP体验好，研报资源多
中信证券 万2-万2.5 大型券商，服务好，但费率偏高
招商证券 万1.5-万2 稳定可靠，APP交互友好

注意：佣金可以联系客户经理谈，新开户有议价空间，一般可以谈到万1-万1.5。

场外基金购买渠道对比

渠道 优点 缺点
支付宝/微信 操作简单，入门方便，基金数量多 申购费率打1折但仍高于部分渠道
天天基金 基金最全，数据详细，费率1折 独立APP需额外下载
券商APP 统一管理所有投资，部分基金免申购费 基金数量可能不如第三方全
基金公司官网 费率最低（部分直销免申购费） 只能买自家基金，管理分散

开户注意事项

  • 一个人最多开3个证券账户（不同券商各一个）
  • 开户免费，不用不产生费用
  • 交易时间才能开户成功（工作日9:00-15:00视频认证环节）
  • 开户后建议顺便开通：创业板（需满2年交易经验）、科创板（需50万资产+2年经验）
  • 如果只是买基金定投，直接用支付宝即可，无需证券账户

七、常见问题

  • Q：股票、指数、基金的区别？ A：股票是单个公司所有权凭证；指数是"一篮子股票"的统计结果，本身不能直接购买；基金是按既定策略买入资产的投资工具，通过买指数基金可以间接投资指数。
  • Q：国债和企业债的主要差异？ A：核心差异是发行主体和信用风险。国债由国家信用担保风险极低；企业债收益更高但存在违约风险。
  • Q：大盘指数下跌和经济下行有直接关联吗？ A：长期相关，短期可以完全背离。股市反映"预期"，经济数据反映"过去"，加上情绪和资金面影响，短期涨跌经常与实体经济脱节。
  • Q：什么是牛市和熊市？ A：牛市指市场持续上涨、投资者乐观；熊市指从高点跌超20%、投资者悲观。熊市适合定投积累便宜筹码，牛市适合收获利润。

八、学习路线建议

  • 理解基本投资品种（股票、债券、基金）
  • 理解牛市熊市概念
  • 理解大盘指数
  • 学习如何开户（证券账户、基金账户）
  • 了解A股交易规则（T+1、涨跌停、交易时间）
  • 学习看基金的关键指标（费率、规模、跟踪误差、历史回撤）
  • 学习定投实操（选哪只基金、定投频率、止盈策略）
  • 了解税费（印花税、管理费、托管费、申购赎回费）
  • 学习基本面分析入门（市盈率PE、市净率PB、ROE）
  • 了解宏观经济指标对市场的影响（GDP、CPI、利率、M2）
