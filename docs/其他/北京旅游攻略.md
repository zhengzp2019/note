# 北京旅游攻略(家庭带娃 · 夏季)

> 本篇聚焦「提前准备」。景点预约政策、放票时间会随季节和政策调整,**临行前 1~2 周务必用官方渠道再核实一遍**(尤其暑期是高峰,放票秒空)。

## 一、通用准备(所有景点都用得上)

### 证件与预约账号
- **每人一张身份证**(带娃的话,孩子的身份证/户口本也带上,很多馆凭有效证件入场)。
- 提前注册好这几个预约入口,别到现场才弄:
  - 故宫:微信搜「**故宫博物院观众服务**」小程序 / 官网 `gugong.ktmtech.cn`
  - 国博:微信「**国家博物馆**」公众号 / 官网 `www.chnmuseum.cn`
  - 天安门广场:微信「**天安门广场预约参观**」小程序
  - 自然博物馆 / 军博 / 科技馆:各自官网或公众号(见下文分述)
- 一个手机号/微信通常一次能给多人预约(有人数上限),**全家出行时提前确认能否一单约齐**。

### 夏季专项(6~8 月北京炎热、多雷阵雨)
- 防晒:遮阳帽、防晒霜、太阳镜;广场和长城几乎无遮荫,给娃备**冰袖/小电扇/防晒衣**。
- 补水:每人 1~2 瓶水,故宫/长城内买水贵;可带保温杯,馆内多有直饮水。
- 雨具:午后常有雷阵雨,备**轻便雨衣**(比伞方便,长城/广场撑伞不便)。
- 时段:上午 8:30~11:00、下午 16:00 后较凉快,**正午避免长时间户外暴晒**,中午安排室内(博物馆)避暑。

### 带娃要点
- **婴儿车**:故宫、长城台阶多,推车吃力;低龄娃建议**轻便伞车 + 腰凳/背带**组合。多数博物馆可推车进,长城和故宫部分区域需抱。
- **寄存**:大件行李、婴儿车、包(人民大会堂尤其严格)提前想好寄存,很多馆入口有寄存柜。
- 备:湿巾、备用衣物、小零食、退烧药/创可贴等常用药。
- 母婴室:大馆基本都有,入场时问工作人员或看导览图。

## 二、景点预约总览表

> **预约提前天数 = 官方开放预约的窗口**(如「提前 7 天」= 出行日前第 7 天开始能约)。暑期高峰放票即抢,**建议放票当天一早就约**。天数/票价可能调整,以官方当日公告为准。

| 景点 | 预约方式 | 提前时间(建议) | 放票/抢票提示 | 门票 | 闭馆日 |
|---|---|---|---|---|---|
| **故宫博物院** | 故宫观众服务小程序/官网 | **提前 7 天** | 每天定量,旺季秒空,放票当天一早抢 | 旺季约 60 元;1.2m 以下免票 | 周一(暑期多正常开放) |
| **天安门广场** | 天安门广场预约小程序 | **提前 1~10 天**(实名) | 白天场约当天即可;看升旗需另约、极早 | 免费 | 无 |
| **国家博物馆** | 国博公众号/官网 | **提前 1~7 天** | 极火爆,放票即抢,凭身份证入场 | 免费 | 周一 |
| **人民大会堂** | 现场/线上购票 | **随时**(先查当天是否开放) | 仅非会议期开放,时段不固定 | 约 30 元 | 会议期不开放 |
| **国家自然博物馆** | 官网/公众号 | **提前 1~7 天** | 暑期亲子高峰,放票很快满,尽早抢 | 免费 | 周一 |
| **军事博物馆(军博)** | 官网/公众号 | **提前 1~7 天** | 凭身份证入场 | 免费 | 周一 |
| **中国科技馆** | 官网/公众号 | **提前约 7 天** | 需购票,暑期/周末现场常无票,务必网上买 | 主展厅约 30 元,儿童优惠;儿童乐园另购 | 周一 |
| **八达岭长城** | 官方购票平台 | **提前 1~7 天**(实名分时段) | 暑期热门,早约;慕田峪人少可现场购 | 旺季约 40 元 | 无 |

**通用规律**:多数博物馆**提前 7 天**开放预约、**周一闭馆**;免费馆(国博/自博/军博/天安门)**名额靠抢**,收费馆(故宫/科技馆/长城)**要提前买票**。放票时间各馆不同(多为**提前 7 天的 0 点或早 8~9 点**),临行前先确认好具体放票时刻,定好闹钟。

## 三、景点分述(按区域归类,方便排动线)

### 【天安门广场核心区】故宫 + 天安门 + 国博 + 人民大会堂

这四个都在天安门广场周边,**步行可达,但一天全塞下太累,尤其带娃**。建议拆成 2 天:一天故宫,一天广场+国博(+人民大会堂看时间)。

#### 1. 故宫博物院
- **预约**:官方一般**提前约 7 天**开放预约,**每天定量、旺季秒空**,放票后尽早抢。周一闭馆(暑期 7~8 月周一多正常开放,以官网公告为准)。
- **门票**:旺季全价约 60 元;学生等半价;**身高 1.2m 以下儿童免票**(仍需预约名额,注意核实)。珍宝馆、钟表馆另收费。
- **入场**:仅从**午门(南)**进,**神武门/东华门(北/东)**出,**单向不能回头**。夏季 8:30 开馆,**建议约上午最早场**,趁凉快且人少。
- **带娃/夏季**:全程 3~4 小时、步行多、遮荫少,中轴线(午门→三大殿→后三宫→御花园)为主线,体力有限就走中轴线出神武门。神武门出来正对**景山公园**,可登万春亭俯拍故宫全景。
- **动线提示**:从神武门出,别原路返回;打车/地铁需走到东华门或西侧。

#### 2. 天安门广场 & 升降旗
- **预约**:目前**广场需实名预约**(免费),**提前几天**开放名额,建议约。看升旗要非常早(按当天日出时间,夏季约 4:40~5:00),**带娃看升旗性价比低**,可只白天逛。
- **安检**:严格,**别带违禁品**(打火机、刀具、大瓶液体等),排队时间长,备水和遮阳。

#### 3. 中国国家博物馆(国博)
- **预约**:**免费但必须提前预约**,极其火爆,**放票即抢**(通常提前 1~7 天,以公告为准)。周一闭馆(节假日除外)。凭身份证入场。
- **看点**:古代中国基本陈列(后母戊鼎、四羊方尊等)最值得看;带娃可挑**明星文物打卡** + 临时展,别贪多。
- **带娃/夏季**:室内恒温,是**正午避暑好去处**;馆大,提前在导览图上圈好想看的展厅,避免暴走。有母婴室、餐厅。

#### 4. 人民大会堂
- **参观**:**非会议期间才对外开放**,开放时段不固定,**去前务必查当天是否开放**。现场/线上购票,约 30 元。
- **重点提醒**:**安检极严,基本不能带包**(需寄存,别带大包/婴儿车麻烦),液体、相机脚架等受限。带娃时权衡,时间紧可舍。

---

### 【单独区域】自然博物馆 / 军博 / 科技馆 —— 带娃重点推荐

#### 5. 国家自然博物馆(原北京自然博物馆,天桥地区)
- **预约**:**免费,需提前网上预约**(官网/公众号),**周一闭馆**。暑期亲子高峰,**放票很快约满,尽早抢**。
- **带娃**:**恐龙化石、古哺乳动物**是娃最爱,还有互动展项,**非常适合带娃**,室内避暑。位置离天坛近,可与天坛连游。

#### 6. 中国人民革命军事博物馆(军博,木樨地/军事博物馆站)
- **预约**:**免费,需提前预约**,**周一闭馆**。凭身份证入场。
- **带娃**:大量**飞机、坦克、火炮、导弹**实物,男娃普遍很喜欢;馆体量大,室内避暑;广场有露天展品(夏季注意防晒)。

#### 7. 中国科学技术馆(科技馆,奥林匹克公园)
- **预约/门票**:**需购票**(主展厅约 30 元,儿童优惠;**儿童科学乐园**等特色展厅单独购票)。**周一闭馆**,**暑期/周末极热门,务必提前网上购票**(现场常无票)。
- **带娃**:**全北京最适合带娃**的场馆之一,大量互动体验;**低龄娃走「儿童科学乐园」**,大点的娃走主展厅。建议**安排大半天**,室内避暑。周边即奥林匹克公园、鸟巢水立方,傍晚可顺路看夜景。

---

### 【近郊·长城】八达岭 vs 慕田峪(选一个即可)

长城离市区约 1.5~2 小时车程,**单独占一整天**,夏季+带娃务必错峰、备足水和防晒。

| | 八达岭长城 | 慕田峪长城 |
|---|---|---|
| 特点 | 最经典、名气大 | 相对人少、景美 |
| 人流(暑期) | 极多,需**实名预约** | 较少,体验更好 |
| 缆车/滑道 | 有缆车、滑车 | **缆车上 + 滑道下**,娃很爱 |
| 交通 | 市郊铁路 S2 线 / 877 路公交 / 高铁,较方便 | 公共交通较绕,**自驾或包车更省心** |
| 带娃推荐度 | 人多台阶陡,一般 | **更推荐**(人少、有滑道、坡缓些) |

- **预约**:八达岭**必须实名预约**分时段,暑期热门早约;慕田峪现场/线上购票,人少些。
- **夏季/带娃**:城墙上**几乎无遮荫**,上午早点上、避开正午;台阶陡,**婴儿车用不上,备背带/腰凳**;充足饮水,山上物价高。
- **量力而行**:登长城很耗体力,带娃**上缆车、走一小段城墙打卡**即可,别硬爬到最高烽火台。

## 三、建议行程节奏(4~5 天参考,可增减)

> 原则:**每天 1 个主场 + 就近搭配**,正午安排室内避暑,不贪多,给娃留休息缓冲。

- **Day 1** 故宫(上午最早场,中轴线)→ 出神武门登景山俯拍 → 下午休整。
- **Day 2** 天安门广场(白天)→ 国博(正午避暑,重点文物)→ 视开放情况看人民大会堂外观/参观。
- **Day 3** 军博 或 自然博物馆(二选一,看娃兴趣;自然博物馆可连天坛)。
- **Day 4** 中国科技馆(大半天)→ 傍晚奥林匹克公园/鸟巢水立方夜景。
- **Day 5** 长城一日(推荐慕田峪,缆车+滑道)。

## 四、临行前 Checklist

- [ ] 故宫、国博、天安门、自然博物馆、军博、科技馆、八达岭 —— **逐个确认放票时间并预约成功**(截图留存二维码/凭证)
- [ ] 确认各馆**周一是否闭馆**、当天是否有临时闭馆公告
- [ ] 人民大会堂**当天是否开放参观**
- [ ] 全员身份证 + 儿童证件
- [ ] 夏季:遮阳帽/防晒/冰袖/轻便雨衣/充足饮水
- [ ] 带娃:伞车或背带、湿巾、备用衣物、常用药、零食
- [ ] 交通:长城当天出行方式(高铁/S2/包车)提前定好

> 提示:以上预约天数、票价、开放时间均可能调整,**一切以各官方渠道当日公告为准**。
