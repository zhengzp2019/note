## 怎么用这份计划

把它当成一门"个人理财自习课",不是刷视频清单。

- **节奏**：每天 30 分钟，一次只啃一个知识点。看完在 [基本概念](基本概念.md) 或单独笔记里补几行，比看 10 个视频都管用。
- **顺序**：从上往下，别跳。每个知识点建立在前一个之上。
- **看视频三原则**：① 看发布日期，财经内容优先近 1-2 年；② 凡是"荐股""带你翻倍""稳赚"一律划走，正经博主只讲方法和风险；③ 边学边用小钱实践（几百块定投），实践 1 次胜过看 10 遍。
- **打勾**：学完把对应的 `[ ]` 改成 `[x]`，进度一目了然。

每个知识点的格式：**学什么** → **搜什么**（B站关键词）→ **笔记记什么** → **小任务**。

## 第 1 周：地基 + 认识工具（快速复习，你已有基础）

这周内容 [基本概念](基本概念.md) 里大多有，目的是"看视频把文字变成理解"，不用记太多。

- [x] **Day 1｜复利与通胀**
  - 学什么：为什么"时间"是散户最大的武器；不投资也是一种亏损。
  - 搜什么：`复利 72法则`、`通货膨胀 为什么钱越来越不值钱`
  - 笔记记什么：用 72 法则算一次——年化 8% 需要几年翻倍？9年
  - 小任务：查一下自己活期/余额宝现在的年化，对比通胀 2-3%。

- [ ] **Day 2｜风险与收益**
  - 学什么：高收益必然高风险，"低风险高收益"=骗局。
  - 搜什么：`风险与收益 关系`、`半佛仙人 理财 骗局`
  - 笔记记什么：列出你听过的 3 个"高收益"产品，标注风险在哪。

- [ ] **Day 3｜投资品种全景**
  - 学什么：货基/国债/债基/股票/基金/黄金分别是什么、风险排序。
  - 搜什么：`投资品种 有哪些 区别`、`货币基金 债券基金 区别`
  - 笔记记什么：画一条"低风险→高风险"的横轴，把品种排上去。

- [ ] **Day 4｜股票 vs 指数 vs 基金**
  - 学什么：三者区别（这是最容易混的）。指数本身买不了，靠指数基金间接投。
  - 搜什么：`股票 指数 基金 区别`、`什么是指数基金`
  - 笔记记什么：一句话分别定义三者。

- [ ] **Day 5｜牛市与熊市 + 大盘指数**
  - 学什么：牛熊定义、"熊市播种牛市收获"、上证指数是什么。
  - 搜什么：`牛市 熊市 是什么`、`上证指数 沪深300 是什么`
  - 小任务：打开行情软件，看一眼沪深300现在点位和近一年走势。

## 第 2 周：基金精讲（个人理财的主力，重点）

普通人理财 80% 靠基金，这周务必学扎实。

- [ ] **Day 6｜主动基金 vs 被动（指数）基金**
  - 学什么：基金经理选股 vs 跟踪指数；为什么长期多数主动基金跑不赢指数。
  - 搜什么：`主动基金 被动基金 区别`、`为什么推荐指数基金`
  - 笔记记什么：两者的费率差异、适合人群。

- [ ] **Day 7｜宽基 vs 行业 vs 策略指数**
  - 学什么：沪深300/中证500(宽基)、白酒/医药/科技(行业)、红利/价值(策略)的区别。
  - 搜什么：`宽基指数 行业指数 区别`、`沪深300 中证500 创业板 区别`
  - 笔记记什么：新手为什么优先宽基？(答案：分散、不押赛道)

- [ ] **Day 8｜看懂基金四要素**
  - 学什么：费率、规模、跟踪误差、最大回撤——挑基金看这四个。
  - 搜什么：`如何挑选指数基金`、`基金 跟踪误差 是什么`
  - 笔记记什么：把这四个指标的"好坏标准"记下来（如规模>2亿、跟踪误差越小越好）。
  - 小任务：在天天基金/支付宝里打开一只沪深300指数基金，把这四个数找出来。

- [ ] **Day 9｜ETF vs 场外基金**
  - 学什么：ETF像股票一样场内买卖、费率低；场外基金申购赎回、适合定投。
  - 搜什么：`ETF 和 场外基金 区别`、`ETF 怎么买`
  - 笔记记什么：你更适合哪种？(定投新手→场外；想低费率灵活→ETF)

- [ ] **Day 10｜基金费用**
  - 学什么：管理费、托管费、申购赎回费；持有时间越短费率越高。
  - 搜什么：`基金 费率 有哪些`、`基金 申购费 赎回费`
  - 笔记记什么：为什么频繁买卖基金会吃掉收益？

## 第 3 周：定投实操（学完就能开始动手）

- [ ] **Day 11｜定投原理与微笑曲线**
  - 学什么：固定时间投固定钱，高位少买低位多买，摊平成本；先跌后涨最赚（微笑曲线）。
  - 搜什么：`基金定投 原理`、`定投 微笑曲线`
  - 笔记记什么：定投最怕什么？(答：一路上涨、或下跌时停止)

- [ ] **Day 12｜定投选品、频率、金额**
  - 学什么：选宽基指数基金；月投/周投差别不大；金额=闲钱能承受的。
  - 搜什么：`定投 选哪只基金`、`定投 频率 金额`
  - 小任务：确定你的第一只定投标的 + 每期金额（哪怕 100 元）。

- [ ] **Day 13｜定投止盈策略**
  - 学什么：定投的核心难点是"何时卖"。目标止盈(如+30%)、估值止盈、分批止盈。
  - 搜什么：`定投 止盈 策略`、`基金 什么时候卖出`
  - 笔记记什么：给自己定一条止盈规则并写下来。

- [ ] **Day 14｜真正开始定投**
  - 小任务：在支付宝/天天基金设置一笔自动定投（金额要小，重在体验流程）。
  - 笔记记什么：记下你的定投计划——标的、金额、频率、止盈线。

## 第 4 周：资产配置（从"买一只"到"搭一个组合"）

- [ ] **Day 15｜为什么要配置**
  - 学什么：不把鸡蛋放一个篮子；不同资产相关性低→整体波动更小。
  - 搜什么：`资产配置 是什么`、`为什么要资产配置`

- [ ] **Day 16｜经典组合**
  - 学什么：股债平衡(如股6债4)、永久组合、"100-年龄"股票占比法则。
  - 搜什么：`股债平衡 组合`、`永久投资组合`
  - 笔记记什么：按你的年龄和风险偏好，写一个自己的配置比例。

- [ ] **Day 17｜再平衡**
  - 学什么：定期把偏离的比例调回去，本质是"高抛低吸"的纪律。
  - 搜什么：`资产 再平衡 是什么`
  - 笔记记什么：多久再平衡一次？(常见：每年1次或偏离5%时)

- [ ] **Day 18｜应急资金与闲钱原则**
  - 学什么：留 3-6 个月生活费；只用闲钱投资；不加杠杆。
  - 搜什么：`应急资金 怎么留`、`闲钱投资`
  - 小任务：算一下你该留多少应急金，放在货基里。

## 第 5 周：基本面入门（想选股或买主动基金再学）

只买指数基金的话，这周可以先跳过，以后想深入再回来。

- [ ] **Day 19｜市盈率 PE**
  - 学什么：股价/每股收益，衡量"贵不贵"、多少年回本。
  - 搜什么：`市盈率 PE 是什么 通俗`
  - 笔记记什么：PE 高低要和同行业比，不能单看数字。

- [ ] **Day 20｜市净率 PB 与 ROE**
  - 学什么：PB=股价/净资产；ROE=净资产收益率，衡量公司"赚钱能力"。
  - 搜什么：`市净率 PB`、`ROE 净资产收益率 是什么`
  - 笔记记什么：巴菲特为什么最看重 ROE？

- [ ] **Day 21｜股息率与分红**
  - 学什么：股息率=分红/股价，红利策略的核心指标。
  - 搜什么：`股息率 是什么`、`红利指数 是什么`

- [ ] **Day 22｜给指数估值（进阶但实用）**
  - 学什么：用指数的 PE/PB 百分位判断当前"贵还是便宜"，指导定投加减仓。
  - 搜什么：`指数估值 百分位`、`螺丝钉 估值表`
  - 小任务：查一下沪深300现在的PE百分位，处于高估还是低估区。

## 第 6 周：宏观常识 + 避坑（看懂财经新闻）

- [ ] **Day 23｜GDP 与 CPI**
  - 学什么：GDP=经济总量增速，CPI=物价涨幅(通胀)。
  - 搜什么：`GDP CPI 通俗解释`、`小Lin说 CPI`

- [ ] **Day 24｜利率与加息降息**
  - 学什么：利率是资金的价格；加息→股市承压，降息→利好资产。
  - 搜什么：`加息 降息 对股市影响`、`利率 是什么`
  - 笔记记什么：为什么"美联储加息"会影响全球市场？

- [ ] **Day 25｜M2 与货币政策**
  - 学什么：M2=市场里的钱总量；放水/收水对资产价格的影响。
  - 搜什么：`M2 是什么`、`货币政策 宽松 紧缩`

- [ ] **Day 26｜常见骗局与避坑**
  - 学什么：庞氏骗局、杀猪盘、荐股群、虚假理财App的套路。
  - 搜什么：`理财 骗局 套路`、`半佛仙人 杀猪盘`
  - 笔记记什么：列出 3 条"一看就是骗局"的特征。

- [ ] **Day 27｜行为金融——你的对手是自己**
  - 学什么：追涨杀跌、损失厌恶、锚定效应等心理误区。
  - 搜什么：`行为金融 投资 心理误区`、`追涨杀跌 为什么`
  - 笔记记什么：回想自己有没有过情绪化决策。

- [ ] **Day 28｜复盘 + 制定长期计划**
  - 小任务：回看整份笔记，写一份自己的"投资纪律"——买什么、投多少、什么时候卖、绝不做什么。
